# Quick-Reference: Banned Phrases by Category

This is a condensed lookup table. SKILL.md has the full pattern descriptions.

## 1. Throat-Clearing Openers

`"Here's the thing"` `"Here's what"` `"Let me be clear"` `"The uncomfortable truth is"` `"It turns out"` `"The real [X] is"` `"Let's dive in"` `"Let's explore"` `"Can we talk about"` `"The truth is"` `"I'll say it again"` `"I'm going to be honest"` `"Here's the problem though"`

## 2. Emphasis Crutches

`"Full stop"` `"Period."` `"Let that sink in"` `"Make no mistake"` `"This matters because"` `"Here's why that matters"` `"Here's the kicker"` `"The best part?"`

## 3. Business Jargon

`navigate` `unpack` `lean into` `landscape` `game-changer` `double down` `deep dive` `take a step back` `moving forward` `circle back` `on the same page` `at the end of the day` `when it comes to` `in a world where`

## 4. AI Vocabulary (Kill These)

`actually` `additionally` `align with` `at its core` `crucial` `delve` `enduring` `enhance` `fostering` `garner` `highlight` `interplay` `intricate` `key (adj.)` `landscape (abstract)` `pivotal` `quiet/quietly` `showcase` `tapestry` `testament` `underscore` `valuable` `vibrant`

## 5. Meta-Commentary & Signposting

`"Plot twist:"` `"Spoiler:"` `"Hint:"` `"The rest of this"` `"In this section"` `"As we'll see"` `"I want to explore"` `"X is a feature, not a bug"` `"Dressed up as"` `"You already know this, but"` `"creeps in"` `"Let me walk you through"`

## 6. Adverbs (Kill ALL)

`really` `just` `literally` `genuinely` `honestly` `simply` `actually` `deeply` `truly` `fundamentally` `inherently` `inevitably` `interestingly` `importantly` `crucially` — plus every other -ly word

## 7. Vague Declaratives / LLM-Safe Truths

`"Consistency is important"` `"The implications are significant"` `"The reasons are structural"` `"The stakes are high"` `"The consequences are real"` `"Building relationships takes time"` `"Success requires hard work"`

If no one disagrees, cut it.

## 8. Chatbot Artifacts

`"I hope this helps"` `"Let me know if"` `"Would you like me to"` `"Certainly!"` `"Great question!"` `"You're absolutely right"`

## 9. 2026 Updates (Forbes)

`"quietly" / "quiet [noun]"` `"Here's the kicker"` `"Honestly? [unremarkable statement]"` `"You're not imagining it"` `"You're not alone"` `"Are you ready to go deeper?"` `"Do you want to sit with that?"` `"I'm going to state this as clearly as possible"` `"Here's the part most people miss"` `"Here's the breakdown"`

## 10. Reassurance Kickers / Therapist Mode

`"And that's okay"` `"There's nothing wrong with that"` `"You're not broken"` `"no shame in"` `"it's completely normal"`

## 11. Formulaic Section Headings

`"Challenges and Future Prospects"` `"Despite challenges, continues to thrive"` `"Challenges and Legacy"` `"Future Outlook"`

## 12. Punctuation

| Type | Rule |
|------|------|
| Em dashes (—) | Banned. Use periods, commas, or colons |
| Boldface overuse | Only for actual headings/UI labels |
| Curly quotes | Use straight quotes |
| Emojis | Banned in prose |
| Title Case in headings | Use sentence case |

## 13. Narrative & Structural Tells (Category 7) — needs whole piece

These are the StoryScope "shape of the story" tells. Reach for them when a piece is *clean at sentence level* but still reads machine-made. Each fix is structural, not a find-replace.

| # | Tell | Surface "clean", but machine | Fix |
|---|---|---|---|
| 7.1 | Theme over-explained | "Mira understood love was about letting go." | Let the ending withhold the lesson. |
| 7.2 | Single-track plot, no subplots | One clean causal line, everything serves the main thread | Add an unresolved side-thread. |
| 7.3 | Tidy closure + acceptance endings | Everything resolves, warm conclusion | Dangle one thread; leave ambiguity. |
| 7.4 | Embodied emotion / weather-mirroring | "Her throat tightened," rain mirrors sadness | Name the emotion directly sometimes. |
| 7.5 | Morally clean choices | Protagonist's move is legibly right | Add a real cost / gray choice. |
| 7.6 | No temporal complexity | Linear timeline only | Flashback, time-jump, withheld cause. |
| 7.7 | Vague allusion, no outside world | Gestures at "the old ways" | Name a real text, place, object. |
| 7.8 | Dialogue debates the theme | Characters philosophize in dialogue | Dialogue should pursue agendas. |
| 7.9 | Low rarity / too blueprint-clean | No odd beat, everything is tidy | Add one unmotivated, specific detail. |

**RESTRUCTURE rule:** fix story-shape before sentences. Pick only the 2-4 tells the piece is worst at. No-fabrication applies.
